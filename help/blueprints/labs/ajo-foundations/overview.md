# 概述

## 您将学习的内容

1. **Adobe Journey Optimizer架构和功能：**
   - 了解如何在Adobe Experience Platform上原生构建AJO以及它在个性化栈栈中的位置
   - 探索支持编排的实时客户历程的核心功能
1. **数据存储：**
   - 区分AJO中的实时客户配置文件和关系存储
   - 配置和使用这两个数据存储区的实践实践
1. **编排的营销活动：**
   - 了解消息投放和渠道配置背后的技术构建块
   - 构建和启动编排的营销活动，包括配置电子邮件渠道
1. **历程和决策：**
   - 了解历程的技术构成块以及它们如何使用Real-Time Customer Profile
   - 了解Experience Edge和Edge Decisioning如何实现实时会话中个性化
   - 探索决策策略、排名和人工智能内容创作



## 目标受众

- 解决方案架构师
- 企业架构师
- 营销人员和营销活动经理
- 开发人员
- Journey Orchestration Specials



## 推荐的体验或熟悉度

- 历程编排或营销活动管理概念
- 对Adobe Experience Platform和Real-Time Customer Profile的一般了解
- 使用REST API
- 电子邮件和跨渠道消息传递概念
- 接触CDP、营销自动化或其他市场技术平台
