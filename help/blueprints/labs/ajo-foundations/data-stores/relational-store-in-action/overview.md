# 正在运行的关系存储

## Lab概述

在本视频中，您将了解关系存储如何与实时客户档案集成，以及您将在本实验室中执行什么操作来浏览关系架构、设置档案定位Dimension以及构建和测试编排的营销活动。

>[!VIDEO](https://video.tv.adobe.com/v/3486539/)

## 学习目标

- 浏览架构并查看关系
- 设置配置文件Target Dimension
- 使用各种工作流活动构建编排的营销活动
- 使用读取受众活动构建受众，并使用关系架构中的属性
- 测试活动并了解将AEP受众与关系架构结合使用时的行为
