# 摘要

在本实验中，您配置了一个数据流，并使用Postman向Edge Network发送了一个模拟的Web事件，以观察数据如何通过Adobe Experience Platform流动。

通过确认已创建配置文件并符合实时配置文件中区段的条件，您验证事件已由多个平台服务处理。 您还可以验证该配置文件是否存在于Edge中，确认该事件存储在数据湖中，并观察到由于其计划的批量更新过程，该配置文件尚未出现在配置文件快照数据集中。

通过这些步骤，您演示了事件如何在Adobe Experience Platform的Edge、实时配置文件和数据湖层中移动。
