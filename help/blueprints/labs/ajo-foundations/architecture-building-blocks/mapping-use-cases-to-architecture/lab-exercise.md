# 实验室练习

**在开始之前，您需要以下各项：**

- 将用例映射到架构工作簿 — [打印下面的工作簿]
- 笔、铅笔或荧光笔

下载文件 — [将功能映射到体系结构练习.pdf](assets/lab-exercise-mapping-capabilities-to-architecture-exercise.pdf)

**对于三个Connection 5G使用案例中的每一个，您都将：**

- 阅读用例简介和附录材料
- 回答五个关键的思考问题
- 循环或突出显示所需的AJO架构组件
- 进行最终的编排引擎推荐

处理完所有三个用例，然后继续查看完成时的审核视频。
