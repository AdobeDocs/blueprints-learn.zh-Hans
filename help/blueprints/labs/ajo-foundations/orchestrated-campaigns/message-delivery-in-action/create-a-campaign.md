# 创建营销活动

## 目标

在接下来的步骤中，您将首先创建一个编排好的营销活动。

## 创建营销活动

1. 在左边栏中，单击&#x200B;**营销活动**

   ![单击左侧边栏中的Campaigns](assets/create-a-campaign-click-campaigns.png)

2. 单击&#x200B;**创建营销活动**

   ![单击“创建营销活动”按钮](assets/create-a-campaign-click-create-campaign.png)

3. 选择&#x200B;**业务流程 — 营销**，然后单击&#x200B;**确认**

   ![选择“编排 — 营销”并单击“确认”](assets/create-a-campaign-select-orchestration-marketing.png)

4. 在下面提供Campaign详细信息，完成后，单击&#x200B;**保存按钮**
   - **名称：** `OC-MDL-Campaign-Test`
   - **描述：** `OC Message Delivery Test`

   ![提供营销活动详细信息，然后单击“保存”](assets/create-a-campaign-provide-campaign-details.png)

5. 在继续之前等待确认消息

![营销活动设置已更新确认消息](assets/create-a-campaign-confirmation-message.png)

## 回顾

您已使用配置的所有基本设置创建了一个编排的营销活动，这些设置将在下一组步骤中使用。
