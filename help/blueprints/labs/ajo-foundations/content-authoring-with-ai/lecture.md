# 讲座

## 学习目标

- 解释为什么内容（而非数据或历程）是大规模个性化项目中的主要限制
- 描述四层内容剖析模型：资产、片段、模板和消息
- 区分AJO片段和AEM内容片段，包括每个片段处理传播的方式
- 映射创建、存储、管理、治理、激活和衡量的内容生命周期阶段
- 比较三种内容集成模式：AJO独立版、AJO + AEM Assets和AJO + GenStudio for Performance Marketing
- 识别指示何时从一种模式升级到另一种模式的体系结构信号
- 描述Adobe栈栈中的三个人工智能功能层：内容助手、Firefly自定义模型和统一品牌服务
- 解释人工智能辅助内容工作流中人在回路监督的原则
- 区分真正的个性化与名字插入或资源乘数

## 主要要点

Personalization的规模取决于三个支柱：内容、数据和历程。 大多数企业都在数据和历程编排方面投入了大量资金，但将内容视为事后处理，这恰恰是为什么内容是个性化计划最先突破的地方。 对于AJO架构师而言，将可扩展实施与在其自身的模板无序下折叠的实施区分开来是因为了解如何将内容构建为受管理的系统，而不是一栈一次性资产。

**在本课程中，您已讲到：**

- 论文：个性化不会因为数据而失败，它会因为内容不是作为系统而构建而失败
- 四层内容剖析：Assets（DAM中的原子媒体）、片段（可重用的可视化或表达式块）、模板（锁定区域与可编辑区域）和消息（最终组合的、通道就绪的输出）
- 内容生命周期：创建、存储、管理、管理、管理、激活、测量 — 以及跳过一个阶段时故障如何从左到右地栈叠
- 模式1，AJO独立：最适用于单市场、单渠道、50种以下变体，速度是主要限制时；使用AEM Assets Essentials作为基本的捆绑DAM
- AJO片段存储在AJO中，并作为重复项复制到模板中，不会自动更新，具有30个片段/1个嵌套级别的限制
- 模式2，AJO + AEM：最适合多市场、50多种变体，当治理是主要限制时；AEM成为记录系统，AJO成为激活系统
- AEM内容片段由AJO引用（而不是复制），因此更新会即时传播到每个引用模板、历程和营销活动
- 三种静默中断片段传播的场景：继承中断（已解锁片段）、添加到已发布片段的新个性化属性以及对象级别访问控制(OLAC)标签限制
- 模式3、AJO + GenStudio for Performance Marketing：最适合生产规模和大容量变量生成；需要模式2治理作为硬性先决条件
- 让AI生成保持一致的四大支柱：统一品牌服务、Content Credentials、人在环管理和AJO集成
- 体系结构决策矩阵和内容Supply chain成熟度模型（第1级ad-hoc到5级autonomous），用于诊断客户当前的位置
- 真正的个性化是单个受管模板中的智能变体，而不是名字合并字段或每个区段的单独营销活动
