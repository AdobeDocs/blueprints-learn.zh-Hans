# UI建模

## 将源映射到XDM

获取有关翻译您放置在纸张上的内容的经验，并了解如何发现并映射到XDM **标准**&#x200B;对象和字段而不是创建&#x200B;**自定义**&#x200B;对象和字段。

您会离开的内容：

- 了解Experience Data Model概念在现实生活中的外观的UI知识
- 了解如何在&#x200B;**XDM字段组**&#x200B;的上下文中定义对象和字段
- 了解如何使用架构UI来浏览XDM标准字段组



## 通过UI构建XDM

实际构建Connection 5G客户帐户架构，该架构利用您使用LID方法创建的架构

您会离开的内容：

- 对整体架构组合UI的基本了解
- 了解如何将XDM标准字段组添加到架构
- 了解如何从XDM标准字段组中删除不必要的字段
- 能够在架构中创建和使用自定义字段组
- 了解如何在架构开发😄期间经常保存
- 了解枚举和建议值之间的差异



## 配置配置文件

了解配置要与Real-time Customer Profile一起使用的架构所需的步骤，从身份标记到为查找架构建立关系。

您会离开的内容：

- 能够将字段标记为身份或主要身份
- 在两个架构之间建立关系
- 了解在启用配置文件之前&#x200B;**测试**&#x200B;架构的原因
- 了解&#x200B;**合并架构**&#x200B;并直观地查看其运行情况
