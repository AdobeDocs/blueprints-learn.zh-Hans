# 构建架构

## 架构程序集

作为XDM一部分的所有架构均以相同的方式构成。  架构始终只包含一个类以及一个或多个字段组。 此外，架构的类指示Experience Platform中的其他系统将如何解释数据（即作为基于记录的序列或时间序列）。

![显示由一个类和一个或多个字段组组成的架构的图表](assets/overview-schema-assembly.jpeg "架构程序集")
