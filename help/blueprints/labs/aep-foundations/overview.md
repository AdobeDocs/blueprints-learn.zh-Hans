# 概述

## 您将学习的内容

1. **关系到NoSQL的转换：**
   - 了解Real-time Customer Profile的架构、建模和装配
   - 将LID方法应用于虚拟场景，以便对实时客户进行建模
1. **体验数据模型(XDM)：**
   - 了解XDM的组件及其与Real-time Customer Profile行为的相关性
   - 同时使用UI和API构建模式的实践实践
1. **数据引入和配置文件创建：**
   - 区分Adobe Experience Platform中的各种数据存储
   - 了解批处理源和流式源的数据处理
   - 用于摄取数据和创建用户档案的动手实验室
1. **分段/激活和受众生成：**
   - 了解实时客户资料支持的区段评估表单
   - 区分Hub与Edge配置文件功能
   - 在UI中构建和激活受众，包括使用流目标



## 目标受众

- 解决方案架构师
- 企业架构师
- 开发人员
- 数据工程师
- 数据架构师



## 推荐的体验或熟悉度

- 数据库概念（创建、更新、删除）
- 数据建模概念（行、字段、键等）
- 使用REST API
- 对Adobe Experience Platform的一般了解
- 接触CDP、广告技术、CRM或其他营销技术栈栈
