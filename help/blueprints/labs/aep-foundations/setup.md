# 设置

在启动AEP基础实验室之前，请完成以下设置步骤。 您需要采取哪些步骤取决于您如何参加训练营。

## 要求和访问权限

- 在启动API调用实验室之前，请完成[Postman设置](#postman-setup)。
- 将事件发送到外部目标的Edge激活和受众激活实验室需要访问[webhook.site](https://webhook.site/)。
- LID方法练习需要打印机来打印工作簿，并使用钢笔或铅笔来完成工作。 请参阅[LID方法先决条件](lid-methodology/prerequisites.md)。

## 沙盒设置

>[!NOTE]
>
>如果您正在参加实时培训课程或活动，则已为您部署沙盒 — 请跳过此部分，直接转到下面的Postman设置。

如果您还没有部署了实验室资产的工作沙盒，请完成以下步骤：

- [Developer Console设置](sandbox-setup/developer-console-setup.md)
- [部署说明](sandbox-setup/deployment-instructions.md)

## Postman设置

本课程中的labs需要Postman，无论沙盒如何配置。 请先完成以下操作，然后再继续：

- [Postman安装](postman-setup/postman-installation.md)
- [环境文件](postman-setup/environment-file.md)
- [API收藏集](postman-setup/api-collection.md)
- [沙盒访问](postman-setup/sandbox-access.md)
- [访问令牌](postman-setup/access-token.md)
