# 用例#2 — 追加销售

## 概述

在本视频中，您将了解如何实施追加销售使用案例，该案例针对数据使用率高的客户，以通过付费和直邮渠道进行激活。

>[!VIDEO](https://video.tv.adobe.com/v/3459487/?quality=12&learn=on)



**用例定义**

查找过去6个月总计费数据使用量>140 GB（连续6个月平均）的所有客户。 每月数据使用量>=20GB，并且没有终极电话计划。

激活至Facebook/Google和直邮渠道。

直邮个性化字段：

- 名字用→问候语
- 邮寄地址→用于邮寄
- 计划名称→用于邮寄声明（例如“Eric，立即升级到最终计划！”）

## 方针

对于此用例，我们将评估两个选项：

- 选项#1（使用受众进行聚合）
  - 这将由受众进行聚合
    - 计费数据使用总和>140 GB（过去6个月）
    - 计费数据使用率平均>20 GB（过去6个月）
    - 计费数据使用率高但无Ultimate计划
- 选项#2（使用预先聚合）
  - 这将利用将数据放在用户档案之前完成的聚合
    - 计费数据使用率高但无Ultimate计划(Agg)
