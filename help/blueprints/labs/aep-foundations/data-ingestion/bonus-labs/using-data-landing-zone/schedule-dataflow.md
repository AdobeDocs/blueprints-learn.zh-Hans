# 计划数据流

在&#x200B;**计划**&#x200B;步骤中：

1. 将&#x200B;**频率**&#x200B;设置为“分钟”。
1. 将&#x200B;**时间间隔**&#x200B;设置为15，即15分钟。
1. 打开&#x200B;**回填**&#x200B;选项。

>[!NOTE]
>
>请注意，**开始时间**&#x200B;为UTC时间。
>
>世界统一时间(UTC)是一个全球时间标准，被用作全球时间记录的参考点。 对于分布在全球的团队来说，它提供了不同地区和国家的共同参考，使得在不同时区之间协调活动和安排活动更加容易。
>
>在AEP UI的各个部分，您会看到UTC时间作为时间计划的基础。 UTC时间比伦敦时间晚一个小时。 如果您不确定UTC时间，只需搜索“UTC时间”。

>[!NOTE]
>
>在实践中，**回填**&#x200B;选项对所有文件执行一次性回填，后续运行会获取新文件。

![正在计划数据流运行，并设置了频率、间隔和回填选项](assets/schedule-dataflow-scheduling-dataflow-run.png "正在计划数据流运行")

查看数据流并单击&#x200B;**完成。**

![在单击“完成”之前审阅最终数据流配置](assets/schedule-dataflow-review-final-dataflow.png "审阅最终数据流")

>[!CAUTION]
>
>如果您为数据流选择&#x200B;**运行一次**&#x200B;选项，则以后将无法编辑此计划或更新数据流。 但是，您可以按需运行数据流，即如果您需要摄取新数据，可以再次运行。

单击&#x200B;**完成**&#x200B;后，您将返回&#x200B;**数据流**&#x200B;屏幕。 创建数据流需要几分钟的时间。 请注意，上次数据流运行状态指示&#x200B;**没有运行**。 第一次跑步应该会在几分钟后开始。

![数据流屏幕显示具有无运行状态的新数据流](assets/schedule-dataflow-dataflows-screen-no-runs-status.png "数据流源屏幕")

> [!NOTE]
>
>您需要持续刷新页面才能看到状态更新，因为后端不会将更新推送到UI。

>[!NOTE]
>
>如果您打开了所有警报，则当流量开始运行并成功完成或失败时，您会在浏览器右上角收到警报
