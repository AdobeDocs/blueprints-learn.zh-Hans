# 映射数据

## 概述

在“映射”屏幕中，AI/ML推荐引擎将在源数据集中的字段与架构字段之间自动映射多个属性。 这些自动映射称为直通映射，但需要&#x200B;**仔细检查**，因为经常会出现错误和不正确的映射。



![映射屏幕显示基于AI/ML的直通映射上下文推荐](assets/overview-ai-ml-based-contextual-recommendations.png "基于AI/ML的上下文推荐")

>
