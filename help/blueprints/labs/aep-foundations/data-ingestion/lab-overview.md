# Lab概述

## 目标

这些实验室的目标是帮助您准备好应对数据摄取的实际挑战。 有了这种了解，您将能够处理、管理和指导您的团队如何在生产环境中实施数据。 尽管这个理论很有意思，我们也会花时间去解决一些问题，因为它们会出现，并把我们在这个工具中所看到的东西，与这个训练营中教给我们的更广泛概念联系起来。



## 期待完成的任务

我需要你的专注。 原因如下：数据将是您以后执行的任何实施的基础。

数据问题并不容易。 数据杂乱、不完整、分散，很难导入到您需要的数据系统中。 这些实验旨在让您了解这些场景。

由于您将要接触系统内部，因此这些下一组实验需要注意和专注。 预计您不会一次吸收所有概念，因此请花时间在实验室中寻找方法。



## 简述教学大纲

由于您具有源架构并且已在XDM中定义目标架构，因此您将需要通过映射连接两个架构。 由于此过程需要按字段映射字段，因此您将需要学习一些可加快此过程的技术，同时注意一些常见缺陷：

- 了解直通映射
- 修复AI/ML生成的直通映射
- 使用源数据预览以检查任何数据质量问题

设置架构映射后，您需要将工作投入测试并调试错误和警告：

- 计划数据流运行
- 标记用户档案的数据集
- 处理因必填字段中缺少值导致的错误
- 处理因数据类型不匹配错误导致的错误
- 处理数据摄取错误并从此类故障中恢复
- 反复使用测试数据来生成综合的映射集。
- 验证并验证已成功摄取的数据。

您将了解有关关系和非关系数据摄取方案的上述概念。
