# 流摄取

## 学习目标

在本练习中，我们将把客户帐户数据从流源加载到Adobe Experience Platform数据湖和配置文件。 完成实验后你该放弃什么？

- 创建流式入口
- 从另一个数据流导入映射集
- 从UI获取数据流ID和数据集ID
- 使用REST API摄取事件

>[!IMPORTANT]
>
>在启动本实验之前，请先完成[Postman设置](../../setup.md)。

>[!NOTE]
>
>如果您未在之前的Labs中完成客户帐户架构创建，则可以浏览到架构目录并改用&#x200B;**dep：客户帐户**
