# 流摄取

## 学习目标

在本练习中，我们将把客户帐户数据从流源加载到Adobe Experience Platform数据湖和配置文件。 完成实验后你该放弃什么？

- 创建流式入口
- 从另一个数据流导入映射集
- 从UI获取数据流ID和数据集ID
- 使用REST API摄取事件
