# 验证已摄取的配置文件

## 流验证

验证Adobe Experience Platform中的流数据需要执行一些其他步骤。  请记住，流数据可以写入多个数据库，具体取决于数据集的配置。

| 存储 | 延迟 | 描述 |
| -------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 数据湖 | \~最多60分钟 | 所有流数据的最终存放位置 |
| 配置文件存储 | 平均\~1分钟 但最长可达\~15分钟 | 仅在为配置文件启用基础数据集时处理数据 |
| 标识存储 | 平均\~1分钟 \~10分钟微批次处理净新身份关系 | 仅在为配置文件启用基础数据集时处理数据 |

根据您尝试验证的内容，可能必须转到上面显示的几个不同位置。  在此场景中，您将数据写入配置文件（因为您为配置文件启用了数据集），因此请检查配置文件存储区以查看配置文件是否存在。



## 查找您的配置文件

1. 在UI中，导航到&#x200B;**配置文件 — >浏览**
1. 在“身份命名空间”和“身份值”输入框中输入以下值：
   - **身份命名空间** -> `customerID`
   - **标识值** -> `202208240125`
1. 单击&#x200B;**查看**&#x200B;按钮查找您的个人资料
1. 单击返回行中的&#x200B;**配置文件ID**&#x200B;链接以查看您的配置文件

![浏览配置文件屏幕，显示按customerID搜索后返回的配置文件行](assets/verify-ingested-profile-browse-profile-screen.png "浏览配置文件屏幕")

请查看您的个人资料并验证它是否与您流式传输的内容相匹配。 真酷！

![与流式客户帐户记录匹配的配置文件详细信息视图](assets/verify-ingested-profile-profile-detail-view.png)

>[!NOTE]
>
>鉴于新的身份关系拼接需要\~10分钟延迟，如果您尝试使用电子邮件命名空间查找个人资料，则不会看到响应。
>
>改用customerID命名空间（主要标识）可确保立即查找用户档案。
>
>请记住，配置文件只知道主要身份😄
