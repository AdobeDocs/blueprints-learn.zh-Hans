# 客户洞察

Adobe Customer Journey Analytics可统一来自多个交互渠道和来源的客户数据和行为，以创建客户交互的基于历程的视图。 此类别提供了核心CJA、B2B CJA派生、受众共享到Real-Time CDP以及CJA与Journey Optimizer集成的架构参考。

核心[Adobe Customer Journey Analytics](cja.md)架构包括用于B2B分析和将CJA受众发布到Real-Time CDP的派生。 [Adobe Customer Journey Analytics与Adobe Journey Optimizer集成](cja-ajo-integration.md)架构涵盖了营销活动和历程见解。

## Customer Journey Analytics 用例

常见用例包括：

* 创建受众并将其发布到 Real-time Customer Data Platform
* 顶部/底部转化路径
* 渠道参与度和转化率
* 查看次数最多的内容
* 首要类别和产品
* 哪些营销活动提高了转化率和参与度
* 工具使用分析，以优化自助服务体验

[Customer Journey Analytics用例文档](https://experienceleague.adobe.com/docs/analytics-platform/using/cja-usecases/cja-usecases.html?lang=zh-Hans)中提供了Customer Journey Analytics用例的完整列表。
